# Full source files

This folder is intentionally empty in Git. The full freMTPL2 extracts are large, so they are not committed.

Download them with:

```bash
python scripts/download_raw.py
```

That writes `freMTPL2freq.parquet` and `freMTPL2sev.parquet` here. A smaller committed sample lives in `data/sample` and is what GitHub Actions uses.
